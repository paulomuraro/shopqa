# ShopQA

Projeto de portfólio de Quality Assurance (QA).

## Sobre o projeto

O ShopQA é um projeto desenvolvido para demonstrar conhecimentos
em testes de software, incluindo testes manuais, testes de API
e automação de testes.

## Objetivos

- Elaborar planos de testes
- Criar casos de teste
- Identificar e documentar bugs
- Realizar testes de API
- Automatizar cenários de teste
- Aplicar boas práticas de QA

## Tecnologias e ferramentas

Em desenvolvimento.
